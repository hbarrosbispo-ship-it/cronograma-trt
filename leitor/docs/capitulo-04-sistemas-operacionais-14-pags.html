Atualizado em 16/04/2026.

Sistemas Operacionais (SO) é um dos temas mais cobrados em provas de concursos do TRT e de tribunais em geral. O assunto abrange desde conceitos fundamentais sobre o funcionamento interno do SO até o uso prático de ferramentas do Windows e Linux — exatamente o que o servidor público utiliza no dia a dia.

Neste capítulo, vamos construir a teoria a partir do que as bancas — especialmente a FCC — mais cobram, garantindo que você reconheça e resolva qualquer questão sobre o tema, seja sobre sistemas de arquivos, gerenciamento do Windows 10/11 ou comandos essenciais do Linux.

‼️Cuidado: Devido às atualizações constantes que acontecem nos sistemas operacionais, algumas telas mostradas neste material podem estar diferentes na versão do sistema operacional que você está usando no momento da leitura. Sendo assim, procure sempre abrir as telas mencionadas no seu computador para verificar se o caminho proposto permanece o mesmo.

01 – FUNDAMENTOS DE SISTEMAS OPERACIONAIS

1.1. Conceito, Funções e Arquitetura (Kernel e Shell)

Um Sistema Operacional (SO) é o software principal de um computador, responsável por gerenciar todos os recursos de hardware (processador, memória, disco, dispositivos) e por fornecer uma interface entre o usuário e a máquina. Sem o sistema operacional, nenhum outro programa pode ser executado.

Ao ligar o computador, o processo se inicia pela BIOS/UEFI (firmware gravado na placa-mãe), que realiza o POST (Power-On Self Test) e localiza o setor de boot do disco. O bootloader então carrega o núcleo do sistema operacional na memória RAM, onde os programas passam a ser executados.

⚠️ Caiu em prova: Ao ligar o computador, o sistema operacional e os programas são carregados na memória RAM.

As principais funções de um SO são:

●​ Gerenciamento de processos – controla quais programas estão em execução e

divide o tempo do processador entre eles.

●​ Gerenciamento de memória – controla quais áreas da RAM estão livres ou

ocupadas e implementa a memória virtual.

●​ Gerenciamento de arquivos – organiza o armazenamento em disco através dos

sistemas de arquivos.

●​ Gerenciamento de dispositivos – comunica-se com hardware periférico via drivers.

●​ Interface com o usuário – pode ser gráfica (GUI) ou por linha de comando (CLI).

A arquitetura interna de um SO é dividida em dois componentes fundamentais:

ComponenteO que éAnalogia
Kernel (Núcleo)Parte central do SO. Gerencia diretamente o hardware,O motor de um carro — invisível ao motorista,
processos, memória e dispositivos. Opera no nível mais privilegiado da máquina (modo kernel).mas responsável por tudo.
Shell (Interface)Camada que envolve o kernel e permite que o usuário interaja com o sistema. Pode ser gráfica (Windows Explorer, GNOME) ou textual (Prompt de Comando, Bash).O painel do carro — o que o motorista vê e usa.
📝Anotação: Para sua prova, lembre: o Kernel é o núcleo que conversa com o hardware; o Shell é a interface que o usuário utiliza. O usuário nunca acessa o hardware diretamente.

1.2. Sistemas de Arquivos (FAT32, NTFS, EXT4)

O sistema de arquivos é a estrutura que o sistema operacional utiliza para organizar, armazenar e recuperar dados no disco. Cada sistema operacional possui seus sistemas de arquivos nativos, mas pode ler outros formatos.

A FCC cobra com frequência a identificação dos sistemas de arquivos e suas características — especialmente a distinção entre FAT32, NTFS e os formatos Linux. Veja o resumo abaixo:

Sistema de ArquivosSistema OperacionalCaracterísticas Principais
FAT16Windows antigo / DOSLimite de 2 GB por volume. Sem segurança. Obsoleto.
FAT32Windows / Pen-drivesSuporta volumes maiores que FAT16. Compatível com quase todos os SOs. Sem criptografia ou compressão nativa. Limite de 4 GB por arquivo.
NTFSWindows XP ao 11 (nativo)Sistema nativo moderno do Windows. Suporta criptografia, compressão, permissões de segurança, volumes grandes. É o padrão recomendado.
EXT4Linux (nativo)Sistema de arquivos padrão das distribuições Linux modernas. Suporta volumes e arquivos muito grandes, journaling.
High Sierra (HFS)macOS (antigo)Sistema de arquivos da Apple. Reconhecido pela FCC como formato válido de sistema de arquivos.
⚠️ Caiu em prova: No Windows XP, para formatar um disco é necessário selecionar um sistema de arquivos. O sistema de arquivos nativo do Windows XP, adequado inclusive para unidades de disco grandes e que permite compressão e criptografia de arquivo é conhecido como NTFS.
⚠️ Caiu em prova: NÃO é um formato adotado em sistemas de arquivos usados em computadores o POP3.
Perceba que POP3 é um protocolo de e-mail, e não um sistema de arquivos — questão clássica de pegadinha da FCC.
‼️Cuidado: Não confunda sistemas de arquivos com protocolos de rede. NTFS, FAT32, FAT, EXT4 e High Sierra são sistemas de arquivos. POP3, SMTP, HTTP e DNS são protocolos de rede. A FCC já cobrou essa distinção diretamente.

1.2.1. Memória Virtual e Arquivo de Paginação

Quando a memória RAM está cheia, o sistema operacional utiliza um espaço reservado no disco rígido para simular mais memória. Esse mecanismo é chamado de memória virtual.

O arquivo responsável por isso é o arquivo de paginação (também chamado de arquivo de permuta ou page file). No Windows, ele é um arquivo oculto no disco rígido (pagefile.sys). A RAM + o arquivo de paginação formam a memória virtual do sistema.

⚠️ Caiu em prova: Arquivo oculto no disco rígido que o Windows usa para manter partes de programas e arquivos de dados que não cabem na memória. Tal arquivo mais a memória física, ou RAM, compreendem a memória virtual. Também conhecido como arquivo de permuta é o arquivo de paginação.
📝Anotação: Para a prova: Memória Virtual = RAM + Arquivo de Paginação (no disco). O arquivo de paginação é oculto e gerenciado automaticamente pelo Windows.

02 – MICROSOFT WINDOWS (10 E 11)

As questões sobre Windows nos concursos do TRT focam no uso prático do sistema: como gerenciar arquivos, configurar permissões, usar atalhos de teclado e navegar pelo sistema de configurações. A FCC já cobrou tanto o Windows 7 (presente em questões até 2018) quanto o Windows 10 e 11 (nas provas mais recentes de 2023 a 2025).

2.1. Explorador de Arquivos — Nomenclatura, Extensões e Buscas

Fonte: https://support.microsoft.com/images/pt-br/dbb561d9-6180-4b29-9fef-048d451b3227

O Explorador de Arquivos (File Explorer) é a ferramenta do Windows utilizada para navegar por pastas e arquivos do computador. Ele pode ser aberto pelo atalho Windows + E.

Conceitos fundamentais cobrados em prova:

●​ Arquivos: unidades básicas de armazenamento de dados. Cada arquivo possui um

nome e uma extensão (ex: relatorio.pdf, planilha.xlsx).

●​ Extensão: parte final do nome do arquivo, normalmente indicada após o ponto.

Indica o formato e o programa associado.

💡Exemplo: os seguintes formatos e programas associados:
• .docx → Microsoft Word;
• .pdf → Adobe Acrobat Reader ou leitor de outras empresas/sistemas, sendo inclusive passível de abertura em alguns navegadores de internet;
• .exe → arquivo executável que corresponde a um aplicativo em si ou à instalação de algum arquivo.
‼️Cuidado: os arquivos executáveis podem ter bloqueio de acesso (ausência de permissão) pelo próprio Windows (tipo de conta do usuário) ou pelos antivirus. Referido impedimento decorre do fato de que os arquivos executáveis serem passíveis de apresentar riscos, como a instalação de arquivos que podem comprometer a segurança do usuário e da rede.

●​ Pastas (diretórios): estruturas que organizam arquivos e outras pastas em

hierarquia.

●​ Acesso Rápido: atalho na barra lateral do Explorador que mostra pastas fixadas e

usadas recentemente, como Documentos, Downloads e Área de Trabalho.

⚠️ Caiu em prova: O Explorador de Arquivos permite acessar rapidamente pastas como Documentos, Downloads e Área de Trabalho através do menu 'Acesso Rápido'.
⚠️ Caiu em prova: No Windows 11, para facilitar o acesso, pastas podem ser fixadas no Acesso Rápido do Explorador de Arquivos clicando-se com o botão direito do mouse sobre o nome da pasta e selecionando a opção Fixar no Acesso rápido.

2.2. Gerenciamento de Arquivos e Lixeira

O gerenciamento de arquivos envolve operações de copiar, mover, excluir e restaurar. As bancas adoram cobrar o comportamento do sistema em situações específicas — especialmente relacionadas à Lixeira e ao método arrastar e soltar.

2.2.2. A Lixeira do Windows

A Lixeira é um espaço reservado no HD onde os arquivos excluídos são temporariamente armazenados antes da exclusão definitiva. Isso permite a recuperação de arquivos apagados acidentalmente.

Regras fundamentais da Lixeira:

●​ Arquivos excluídos do HD → vão para a Lixeira e podem ser recuperados.

●​ Arquivos excluídos com Shift + Delete → excluídos permanentemente, não vão

para a Lixeira.

●​ Arquivos de pen-drive ou rede → excluídos permanentemente, não vão para a

Lixeira.

●​ Arquivos maiores que o tamanho configurado da Lixeira → excluídos

permanentemente.

⚠️ Caiu em prova: Considerando-se que o Windows 7 Professional está instalado na unidade C, se uma pasta que contém 9 MB em documentos for apagada do HD, ela será enviada para a lixeira e poderá ser posteriormente recuperada.

2.3. Área de Trabalho, Barra de Tarefas e Visão de Tarefas

Fonte: https://support.microsoft.com/images/pt-br/f5e07aee-c8aa-4a30-85ec-215178f491b8

A Área de Trabalho (Desktop) é a tela principal do Windows, onde ficam ícones, atalhos e a Barra de Tarefas.

Conceitos importantes:

●​ Atalho: ícone que aponta para um arquivo, pasta ou programa. É identificado por

uma seta pequena no canto inferior esquerdo do ícone. Excluir um atalho NÃO apaga o arquivo original.

●​ Snap Layouts (Windows 11): funcionalidade que permite distribuir janelas na tela

em layouts predefinidos (colunas, grades), aproveitando o espaço da tela de forma otimizada.

●​ Múltiplas Áreas de Trabalho Virtuais: recurso que permite criar ambientes de

trabalho separados, cada um com suas próprias janelas abertas.

⚠️ Caiu em prova: Para criar um atalho para um documento na área de trabalho, o usuário deve clicar com o botão direito do mouse sobre o nome do arquivo, selecionar a opção Enviar para e a opção Área de Trabalho (criar atalho).
⚠️ Caiu em prova: A funcionalidade do Windows 11 que permite distribuir as janelas na tela em layouts predefinidos, por exemplo, em colunas, grades ou áreas de maior e menor destaque, é o Snap Layouts.

O Windows 10 e 11 possuem dois mecanismos de segurança nativos distintos, frequentemente confundidos entre si:

2.4.4. Inicialização Dupla (Dual Boot)

O Windows permite a instalação de mais de um sistema operacional no mesmo computador, oferecendo ao usuário a opção de escolha na inicialização. Esse recurso é chamado de Dual Boot ou Inicialização Múltipla.

Regras importantes sobre o Dual Boot:

●​ Cada sistema operacional deve estar instalado em uma partição separada do disco.

●​ Não é necessário ter dois discos rígidos diferentes — basta ter partições separadas

no mesmo disco.

●​ Para alternar entre sistemas, é necessário reiniciar o computador.

●​ A instalação deve ser feita do sistema mais antigo para o mais recente, para evitar

problemas com os arquivos de boot.

⚠️ Caiu em prova: Em um computador com o Windows 7, pode-se instalar mais de um sistema operacional. Este procedimento exige partições separadas para cada sistema operacional. Se o usuário estiver executando um sistema operacional, não poderá executar um programa instalado em outro sistema operacional.
